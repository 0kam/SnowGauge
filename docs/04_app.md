# 04. アプリの使い方（現地作業）

SnowGauge の現地作業は、スマホ（または PC）のブラウザで動く 1 ページのアプリで行います。
本体と Bluetooth でつながり、**時刻合わせ・データ回収・観測スケジュール変更・設置時の照準と基準設定**ができます。
ケーブルは要りません。ボタンは手袋でも押せるように大きくしてあります。

アプリの URL: **https://0kam.github.io/SnowGauge/app/**

---

## 1. 準備（出発前に、電波のあるところで）

### 1.1 使える端末

| 端末 | 使い方 |
|---|---|
| **Android スマホ + Chrome** | 推奨。URL を開くだけで動きます |
| **PC（Windows / macOS / Linux）+ Chrome** | Bluetooth 内蔵か USB Bluetooth アダプタが必要 |
| iPhone / iPad | Safari では動きません。App Store の **Bluefy** というブラウザを入れて、その中で URL を開きます |

### 1.2 ホーム画面に追加する（Android）

1. Chrome で上の URL を開く。
2. 右上の「⋮」メニュー → **「ホーム画面に追加」**（機種によっては「アプリをインストール」）。
3. ホーム画面の SnowGauge アイコンから起動できるようになります。

### 1.3 出発前に一度オンラインで開く

アプリは一度開くとスマホに保存され、**山の中（圏外）でもそのまま動きます**（オフライン優先）。
ただし更新は開いたときにしか取り込まれないので、**現地に行く前に電波のあるところで一度開いてください**。
新しい版が来ると下の方に「新しい版を取得しました。次回起動時に切り替わります」と出ます。その場合はタブを閉じてもう一度開きます。

いま使っている版は、ページ一番下の「ログ」欄の下に **「アプリ版 2026-09-05a」** のように表示されます（この文書はこの版に対応）。

### 1.4 スマホ側の許可

- **Bluetooth** をオンにする。
- Chrome に**位置情報の許可**を与える（「同期」で GPS を使います。Android では Bluetooth 機器を探すのにも位置情報の許可が要ることがあります）。

---

## 2. 本体につなぐ・切る

画面一番上の帯（ヘッダー）に、接続状態と **「接続」** ボタンがあります。

1. 本体のそばで **「接続」** を押す。
2. Chrome の小さな窓に近くの機器が並びます。**`SG-XXXX`**（XXXX は本体ごとに違う英数字 4 桁。本体の名前です）を選び、「ペア設定」を押す。
3. ヘッダーが **「接続中: SG-XXXX」** に変わり、灰色だったボタンが押せるようになります。同時にアプリが本体の時刻・設定・サイト情報を自動で読み込みます。

作業が終わったら **「切断」** を押します。
時刻を合わせていない（本体とスマホの時刻差が 60 秒より大きい）状態で「切断」を押すと、赤い注意
「時刻が未同期です。同期せずに切断するならもう一度押してください」が出て、すぐには切れません。ふつうは先に「同期」を押してください。

> 本体には一度に 1 台しかつながれません。また、つないでいる間は本体の自動観測が続きますが、ライブ表示中の分は飛びます（第 4 節）。

## 3. 画面の 4 つのパネル

### パネル 1「同期」

| 表示・ボタン | 意味 |
|---|---|
| 本体時刻: | 本体の時計（UTC）と、スマホとの差（秒）。差が 60 秒以内なら緑、それ以上なら橙 |
| サイト: | 本体に保存されているサイト名・緯度経度・標高・精度・設定日時。未設定なら「サイト情報なし」 |
| UTC+09:00（同期時にスマホから自動設定） | タイムゾーン。スマホの設定から自動で入るので、操作は不要 |
| 入力欄「サイト名（例: 苗場A）」 | 設置場所の名前。**「同期」を押す前に入力**します。空欄なら前回の名前が残ります |
| **「スマホの時刻・位置で同期」** | メインのボタン。**時刻・タイムゾーン・GPS 位置** を一度に本体へ書き込みます。GPS 取得に最大 20 秒かかります |
| ▸「時刻のみ / 位置を手動入力」 | 開くと補助ボタンが出ます: **「時刻のみ同期」**（GPS を使わない）、緯度・経度・標高 m の入力欄と **「位置を手動で保存」** |

GPS が取れなかったときは、時刻とタイムゾーンだけ書き込まれ、「失敗: 1 件の問題（ログ参照）」と出ます。屋外で空が開けた場所ならもう一度押すか、緯度経度を手動で入れてください。

### パネル 2「観測データ」

| 表示・ボタン | 意味 |
|---|---|
| **「ダウンロードして CSV 保存」** | 本体の記録を全部読み出し、**そのまま CSV ファイルを保存**します。進み具合が下に出ます（`rec_202612.bin: 1200/4000 B` など）。件数が多いと数十秒〜数分 |
| グラフ | 基準値が設定されていれば**積雪深**、なければ**斜距離**の時系列。上端の赤い帯は欠測区間 |
| 「N 件、要確認 n 件（一覧は新しい 30 件…）」 | 読み出した件数のまとめ。**「すべて表示」**で全件に切り替え |
| 表 | 現地時刻（月-日 時:分）/ 距離 / 積雪 / 傾斜 / 電池 / 有効。気になる点がある行は橙色になり、その下に「要確認: 理由」の行が出ます（第 6 節） |
| ▸「もう一度保存 / 生データ」 | **「CSV をもう一度保存」**（同じ内容を再保存）、**「生データ保存」**（本体のファイルそのもの `rec_YYYYMM.bin` と `site.json`。解析で困ったときの保険） |

CSV の中身は [05_data.md](05_data.md) を見てください。

### パネル 3「観測スケジュール」

| 項目 | 意味 |
|---|---|
| 観測開始 / 観測終了 | 自動観測する時間帯（現地時刻、30 分刻み）。**開始と終了を同じにすると終日**。開始が終了より後なら夜をまたぎます（例 17:00 → 05:00） |
| 観測間隔 | 30 分〜24 時間から選ぶ。「自動観測しない」にすると止まります |
| 基準斜距離 d0 / 基準傾斜 θ0 / 基準設定日時 | パネル 4 で設定した基準値の表示（ここでは変えられません） |
| **「保存」** | 変更を本体に書き込む。押すまで本体は変わりません |
| **「再読込」** | 本体の値を読み直す（変更をやめたいとき） |

> 標準的な設定は「終日・3 時間ごと」（8 回/日）です。間隔を短くすると電池が早く減ります。
> 本体は再起動（電池交換など）のあと約 10 分は自動観測を待ちます。すぐ 1 回測らせたいときは、パネル 4 のライブ表示で確認してください。

### パネル 4「設置・基準設定」

| 表示・ボタン | 意味 |
|---|---|
| 基準: | 今の基準値 `d0 = 245 cm, θ0 = 12.30°`、または「未設定（無雪 ZERO か積雪深入力で設定）」 |
| ライブ: | 「停止」か「動作中（センサ通電中、5 分で自動停止）」 |
| 数字のタイル | **斜距離 cm**（センサが測った生の距離）、**鉛直距離 cm**（傾きを補正した真下方向の距離 = 斜距離 × cos 傾斜）、**積雪 cm**（基準値があるときだけ）、**傾斜 °**、**信号強度**、**電池 mV**、**有効/総**（10 回中いくつ有効だったか。`10/10, var 1` のように、ばらつきも出ます） |
| **「ライブ開始」** / **「ライブ停止」** | センサに通電して約 0.25 秒ごとに数字を更新。**照準合わせ用** |
| **「ZERO（無雪の地面）」** | 雪のない地面を測って、それを積雪 0 の基準にする。**2 回押し**（下記）。約 3 秒 |
| 積雪深の選択（0〜400 cm）+ **「積雪深で基準設定」** | すでに雪がある状態で設置したとき。スノープローブ等で測った**今の積雪深**を選んでから押す。**2 回押し**。本体が「今の距離 + 積雪深 ÷ cos 傾斜」を基準 d0 として保存します |
| **「状態更新」** | 基準値とライブの状態を本体から読み直す |
| **「全レコード消去」**（赤） | 本体の記録を全部消す。**2 回押し**。このセッションで「ダウンロードして CSV 保存」を済ませるまで押せません（灰色のまま、下に理由が出ます） |

### 「ログ」欄

一番下。アプリが何をしたか（接続、時刻設定、ファイル名と件数、エラー）が時刻付きで残ります。うまくいかないときはここを見て、必要なら写真に撮って報告してください。その下に「アプリ版 …」があります。

### ボタン操作の共通ルール

- 押すとボタンが「処理中…」になり、終わると画面下に「完了」または「失敗: 理由」が短く出ます。処理中は他のボタンが押せません。
- **2 回押し**が必要なボタン（ZERO・積雪深で基準設定・全レコード消去・未同期での切断）は、1 回目でボタンが
  「確認: 1.5 秒後にもう一度押すと実行」に変わります。**1.5 秒以上あけて、6 秒以内**にもう一度押すと実行されます。1.5 秒以内の連打は無視され、6 秒たつと元に戻ります（手袋での誤操作を防ぐためです）。

## 4. 現地の手順（チェックリスト）

### 設置時

1. 本体を取り付け、電池をつなぐ。アプリで **「接続」** → `SG-XXXX` を選ぶ。
2. 「サイト名」を入力し、**「スマホの時刻・位置で同期」**。「本体時刻」が緑になり、「サイト:」に名前と緯度経度が出ることを確認。
3. **「ライブ開始」**。**斜距離**の数字が出て、**有効/総**が 9/10 以上、**信号強度**が数百以上あるように向きを調整する（雪面・地面に対して、たとえば 20〜30° 斜め下）。数字が `---` のままなら、対象が近すぎる／遠すぎる／向きが外れています。
4. 向きが決まったら **「ライブ停止」**。
5. 基準を作る（どちらか）:
   - 雪がない → **「ZERO（無雪の地面）」** を 2 回押し。
   - 雪がある → プローブで積雪深を測り、選択欄で選んで **「積雪深で基準設定」** を 2 回押し。
   「基準:」に `d0 = … cm, θ0 = …°` が出れば成功。
6. パネル 3 の **観測開始・終了・間隔** を確認し、変えたら **「保存」**。
7. **「切断」**。しばらくして本体の緑 LED が観測のたびに短く光ります（最初の自動観測は約 10 分後以降）。

### 巡回時（データ回収）

1. **「接続」** → `SG-XXXX`。
2. **「スマホの時刻・位置で同期」**（時計のずれを直します。位置は前回と同じでも構いません）。
3. **「ダウンロードして CSV 保存」**。「合計 N 件」と出て、CSV がスマホに保存されます。表とグラフをざっと見て、**電池 mV** と「要確認」の数を控える。
4. （任意）本体の記録を空にしたいときだけ **「全レコード消去」** を 2 回押し。消去しなくても新しい記録は追記されます（2 MB で数年分入ります）。
5. **「切断」**。

## 5. きまりと注意

- **帰る前に必ず「同期」**。本体の時計は電池を抜くとリセットされ、次に電源が入ると「前回の記録の時刻」から動き出します（実際より遅れた時刻）。同期するまでの記録には「時刻推定」が付きます。
- **ライブ表示はセンサに約 120 mA 流れます**（通常の待機は約 0.03 mA = 26 µA）。確認が終わったらすぐ「ライブ停止」。切断すると自動で止まり、5 分たっても自動で止まります。ライブ中に予定時刻が来た自動観測は 1 回飛びます。
- **消去は CSV を保存した後だけ**。アプリ側でもボタンが押せないようにしてあり、本体側でも「このセッションで読み出し済み」でないと拒否します（「ダウンロード前の消去は拒否されました」）。
- 「ZERO」「積雪深で基準設定」は、ライブ表示で距離と傾斜がちゃんと出ている状態で行ってください。出ていないと「測距か傾斜が取れていません」で失敗します。
- 基準値は本体に 1 組だけ保存されます。設定し直すと前の値は上書きされます（CSV には生の距離も入っているので、あとから計算し直せます。05 章）。
- タイムゾーンはスマホの設定が自動で入ります。海外設定のスマホを使わないこと。
- **CSV の保存先（Android）**: Chrome の「ダウンロード」フォルダ（内部ストレージ/Download）。ファイル名は `SG-XXXX_2026-12-31-03-15-20.csv` のように本体名 + 保存時刻。Bluefy（iPhone）ではブラウザのダウンロード先（「ファイル」アプリ内）に入ります。
- 「本体時刻」の差が数秒あるのは正常です。

## 6. 「要確認」に出る言葉の意味

| 表示 | 意味 | どう考えるか |
|---|---|---|
| 測距なし | 100 回のうち有効な距離が 1 回もない | 雪面が遠すぎる／近すぎる、レンズの雪や結露、向きのずれ。次の巡回で目視確認 |
| 有効率低 | 有効な回数が半分未満 | 降雪中・霧・レンズ汚れの可能性。距離は残るが信頼度は低め |
| ばらつき大 | 100 回の距離のばらつき（分散）が 4 cm² 超 | 降雪中、風で揺れる、対象が斜めすぎる |
| レンジ外多 | センサが「測れない」と返した回数が半分超 | 測距なしに近い状態 |
| 時刻推定 | 再起動後、同期前の記録 | 時刻が遅れている可能性。05 章の説明を参照 |
| 時刻なし | 時計が一度も合っていない状態の記録 | 設置時に同期を忘れた。順番だけは正しい |
| 欠測あり | 前の記録から観測間隔の 1.5 倍以上あいている | 電池切れ・再起動・ライブ中のスキップなど |
| 電池低 | 電池電圧が 4400 mV 未満 | 次の巡回で電池交換。通電直後の電圧が 4600 mV を切ると本体は距離測定をやめます |

## 7. オフラインでの使い方

- アプリ本体はスマホに保存されているので、圏外でも「ホーム画面に追加」したアイコンから起動できます。
- 「同期」の位置情報は GPS なので圏外でも取れます（空が見える場所で 20 秒ほど）。
- 更新は電波のあるところで開いたときにだけ取り込まれます（1.3 節）。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 「接続」を押しても `SG-XXXX` が出てこない | 本体は 1〜2 秒に 1 回しか信号を出しません。窓を閉じてもう一度「接続」を押す（数回）。本体に近づく（数 m 以内）。**別のスマホがつながったままになっていないか**確認（つながっている間は見えません）。電池が入っているか確認。それでもだめならスマホの Bluetooth を一度オフ→オン |
| Chrome の機器一覧に何も出ない（Android） | Chrome の位置情報許可と、端末の位置情報（GPS）がオンか確認 |
| 赤い帯「このブラウザは Web Bluetooth に対応していません」 | iPhone の Safari、または Firefox 等。Android/PC の Chrome か、iPhone なら Bluefy を使う |
| ログに「本体 FW が設定グループ未対応: 4d 版が必要」/「キャリブレーション用サービスが本体にありません」 | 本体のファームウェアが古い。[03_firmware.md](03_firmware.md) の手順で Release `fw-2026-09-04` 以降を書き込む |
| 「失敗: 本体の応答がありません（タイムアウト）」 | 電波が弱い。近づいてもう一度。直らなければ「切断」→「接続」 |
| 「本体が前のコマンドを処理中です」 | 数秒待ってからもう一度 |
| ダウンロードの途中で止まる | 「切断」→「接続」→ もう一度「ダウンロードして CSV 保存」（最初からやり直しますが、本体のデータは消えません） |
| 画面が古い／ボタンの表示がこの文書と違う | タブを閉じて（ホーム画面のアイコンからなら一度終了して）開き直す。電波のあるところで開くと最新版になる |
| CSV がどこにあるか分からない | Chrome の「⋮」→「ダウンロード」。「CSV をもう一度保存」で再保存もできます |
| 「切断」が 1 回で切れない | 時刻が未同期です。「同期」を押してから切断するか、承知の上ならもう一度押す |

## 補足

- 記録が 0 件のときは本体側は消去を受け付けますが、アプリの消去ボタンは「ダウンロードして CSV 保存」を一度押した後に有効になります（0 件でも押してください。CSV は作られません）。
- 最初の観測は、本体の再起動から 10 分後以降に始まります（再起動を繰り返した場合はさらに延びます）。設置直後に記録が増えなくても故障ではありません。

## 野外で快適に使うために

### Android（推奨）

1. **アプリ化**: Chrome で https://0kam.github.io/SnowGauge/app/ を開き、メニュー（⋮）→「ホーム画面に追加」（機種により「アプリをインストール」）。ホーム画面のアイコンから全画面で起動し、**圏外でも動きます**。
2. **出発前に一度、電波のある場所で起動**する。これだけで最新版がキャッシュされ、ログ欄の下の「アプリ版」が更新されます（山では更新できません）。
3. **Bluetooth と位置情報を ON** にする。Android では Bluetooth 機器の検索に位置情報の許可が必要な機種があります。最初の接続時に Chrome が「付近のデバイス」「位置情報」の許可を求めたら許可してください。位置情報は「同期」で観測点の座標を記録するためにも使います。
4. **省電力設定に注意**: 画面が消えると Bluetooth 接続が切れる機種があります。ダウンロード中は画面を消さない（設定 → ディスプレイ → 画面消灯時間を長めに）。
5. **手袋**: 設定 → ディスプレイ → 「タッチ感度を上げる」「手袋モード」（機種により名称が異なる）を ON。ボタンは大きく作ってあり、文字入力はサイト名以外ありません。
6. **寒さ**: スマホの電池は氷点下で急に減ります。内ポケットで温めておき、作業は接続 → 同期 → ダウンロード → 切断の順で短く。モバイルバッテリーがあると安心です。

### iPhone / iPad

iOS の Safari と Chrome は Web Bluetooth に対応していません（Apple の制限で、iOS 上のすべてのブラウザが同じです）。**App Store の「Bluefy – Web BLE Browser」**（無料、PNN Soft）を入れ、その中で https://0kam.github.io/SnowGauge/app/ を開いてください。

- Bluefy のブックマークに登録しておくと次回が楽です。ホーム画面アイコンからの起動（PWA）は Bluefy では使えないので、毎回 Bluefy を開きます。
- 圏外での動作は、Bluefy で一度オンラインで開いておけばキャッシュから起動します。ただし iOS はキャッシュを消すことがあるため、**出発前にオンラインで一度開く**ことを必ず行ってください。
- CSV は Bluefy のダウンロード先（「ファイル」アプリ内）に保存されます。
- 手袋モードに相当する設定は iPhone にありません。タッチ対応手袋を使うか、作業中だけ外してください。

### 共通

- **接続できないとき**: 本体は 1〜2 秒ごとに電波を出しています。別のスマホが接続中だと見えません（同時接続は 1 台）。近づいて再検索してください。
- **切断前に「同期」**: 本体の時計はスマホから合わせます。未同期で切断しようとすると警告が出ます。
- **ライブ表示は必ず停止**: 照準合わせ中はセンサに約 120 mA 流れます。停止し忘れても切断か 5 分で自動停止します。
- **消去の前に CSV**: 「ダウンロードして CSV 保存」を押すまで消去ボタンは押せません。
- **画面が古い**: タブを閉じて開き直すと新しい版に切り替わります。「アプリ版」の日付で確認できます。
- **本体なしで練習**: https://0kam.github.io/SnowGauge/app/?demo=1 でサンプルデータ入りの画面を触れます（本体には何も送りません）。
