SnowGauge — TFmini Plus variant / rev.1

SnowGauge 組立ガイド

積雪深ロガー SnowGauge(TFmini Plus 版)をユニバーサル基板で組み立てるための手順書です。電子工作がはじめてでも、部品の向きと配線番号のとおりに進めれば完成するように書いてあります。テスター(電圧測定)だけは使えるようにしておいてください。

1まず全体像

この装置は「ふだんは眠っていて、1日8回だけ起きてレーザーで雪面までの距離を測る」機械です。電気の流れは3系統に分かれます。

眠っている間の消費をとことん減らすため、レーザー距離計は使う瞬間だけ通電します。そのスイッチ役がトランジスタ(2SJ334・2SK4017)です。

2部品図鑑 — 向きの見分け方

左が実物の写真、右がピン配置図です。足に番号がある部品は、向きを間違えると壊れます。はんだ付けの前に毎回この図と見比べてください。

XIAO nRF52840 Senseマイコン
頭脳。時計・Bluetooth・傾きセンサ内蔵。オレンジ色の丸が今回使うピン。
向き: USBコネクタを上にして、左列の上から D0…、右列の上から 5V, GND, 3V3, D7(=RX), D6(=TX)。5Vピンは使いません。
TFmini Plusレーザー距離計
目。赤外レーザーで雪面までの距離を測ります(防水 IP65)。
向き: コネクタは逆挿しできない形ですが、線の色(赤=電源, 黒=GND, 緑=TX, 白=RX)を付属の説明書で必ず確認。
NJU7223F333.3V 変換 ×2個
電池の約6Vを 3.3V に落とす部品(レギュレータ)。1個は常時系、もう1個は TSD20 版で使う予備。
向き: 印字面を手前にして左から 1=出力, 2=入力, 3=GND。F50(5V版)と外見がそっくり——印字「F33/F50」を必ず読む。
NJU7223F505V 変換
TFmini Plus 用に 5V を作るレギュレータ。トランジスタのスイッチの後ろに置くので、測定時しか電気を食いません。
向き: F33 と同じ(1=出力, 2=入力, 3=GND)。
2SJ334Q1 メインスイッチ
5V 系の元栓。マイコンの合図で電池からの電気を入り切りします(Pチャネル MOSFET)。
向き: 印字面を手前にして左から 1=G(合図), 2=D(出口), 3=S(入口=電池側)。
2SK4017 ×2Q2, Q3 小スイッチ
Q2 はメインスイッチ Q1 を操作する係、Q3 は電池電圧の見張り回路を入り切りする係(N チャネル MOSFET)。
向き: 印字面を手前にして左から 1=G, 2=D, 3=S。静電気に弱いので足を触りすぎない。
1N5819D1 逆接保護
電池を逆向きに入れてしまった時に回路を守る一方通行弁(ダイオード)。
向き: 帯(カソード)が回路側、帯なし側が電池+側。逆に付けると全く動きません。
OS-CON 470µF/16VC4 バルクコンデンサ
TFmini が瞬間的に大電流を吸う時の「貯水タンク」。低温に強い特別品。
向き: 極性あり! 長い足が+(5V側)、側面の帯がある側が−(GND側)。逆に付けると壊れます。
0.1µF セラミック ×6C1,C2,C3,C5 ほか
電圧のさざ波を消す小さなコンデンサ。レギュレータの足元(数mm以内)に付けるのがコツ。
向き: なし(どちら向きでも OK)。印字は「104」。
抵抗(カーボン 1/4W)R1〜R7
電流を制限したり、スイッチの誤動作を防いだりする部品。値ごとに色の帯が違います。
向き: なし。1MΩ=茶黒緑金 / 100kΩ=茶黒黄金 / 10kΩ=茶黒橙金 / 1kΩ=茶赤赤金。自信がなければテスターで測って仕分け。

3配線図 — 線は全部で30本

上の赤い線が「VBATレール」(電池+の共通線)、下の黒い線が「GNDレール」(電池−の共通線)。ユニバーサル基板ではこの2本をすずメッキ線などで通しておき、各部品からそこへつなぎます。丸数字は §4 のチェックリストの番号と対応しています。

電池+ (VBAT) GND 3.3V 5V(測定時のみ) センサON合図 Q1ゲート 見張りON合図 電圧測定 UART 送信→白 UART 緑→受信

※ 線が交差している所はつながっていません。つながる所には黒丸(●)を描いてあります。C1・C2・C3・C5(0.1µF)と C6(10µF)は図を簡単にするため省略——各レギュレータの IN-GND 間と OUT-GND 間、XIAO の 3V3-GND 間に、それぞれ足元最短で付けます(チェックリスト⑥⑦⑯参照)。

4組立チェックリスト — この順番で

番号は配線図の丸数字と同じです。1本つなぐごとにチェックし、各ステップ最後の「テスター確認」に合格してから次へ進んでください。順番どおりに作ると、高い部品(XIAO・TFmini)を接続する前に電源の安全を確認できます。

STEP 1電源部(常時ON系)をつくる

番号線の種類どこから → どこへ
①電池+電池ボックスの赤線 → D1 の帯なし側
②電池+D1 の帯あり側 → VBATレール
③GND電池ボックスの黒線 → GNDレール
④電池+VBATレール → U1(F33)の2番:IN
⑤GNDU1 の3番:GND → GNDレール
⑥部品C1(0.1µF)を U1 の 2番-3番の間、足元最短で
⑦部品C2(0.1µF)+C6(10µF)を U1 の 1番-GND の間に

テスター確認(電池を入れて)

  • VBATレール − GNDレール間: 約 5.7〜6.1V(電池電圧よりダイオードの分 0.2〜0.35V 低い)
  • U1 の 1番(OUT) − GND間: 3.25〜3.35V
  • ここで電圧が出ない/おかしい場合は D1 の向きと U1 の印字(F33 か)を確認

STEP 2スイッチと 5V 系をつくる

番号線の種類どこから → どこへ
⑧電池+VBATレール → Q1(2SJ334)の3番:S
⑨部品R5(100kΩ)を Q1 の1番:G と VBATレールの間に(眠っている間スイッチを確実にOFFにする係)
⑩ゲートQ2(2SK4017)の2番:D → Q1 の1番:G
⑪GNDQ2 の3番:S → GNDレール
⑫合図XIAO の D2(あとで挿すソケット位置)→ R3(10kΩ)→ Q2 の1番:G
⑬部品R4(100kΩ)を Q2 の 1番:G と GNDレールの間に
⑭電池+Q1 の2番:D → U2(F50)の2番:IN
⑮GNDU2 の3番:GND → GNDレール
⑯部品C3(0.1µF)を U2 の 2番-3番間、C5(0.1µF)を 1番-GND間に
⑰5VU2 の1番:OUT → 5Vライン(TFmini へ向かう線)
⑱部品C4(OS-CON 470µF)を 5Vライン(+)と GNDレール(−)の間に。長い足が5V側!

テスター確認(XIAO はまだ挿さない)

  • なにもしない状態: 5Vライン − GND間 = 0V(スイッチOFFが正常)
  • ジャンパ線で「R3 の XIAO側」を U1 の 3.3V出力に触れさせる: 5Vライン = 4.9〜5.1V
  • ジャンパ線を離す: 0V に戻る

STEP 3電池の見張り回路をつくる

番号線の種類どこから → どこへ
⑲測定VBATレール → R1(1MΩ)→ 中間点(=ADCノード)
⑳測定中間点 → R2(1MΩ)→ Q3(2SK4017)の2番:D
㉑GNDQ3 の3番:S → GNDレール
㉒合図XIAO の D3(ソケット位置)→ Q3 の1番:G
㉓部品R6(100kΩ)を Q3 の 1番:G と GNDレールの間に
㉔測定中間点 → XIAO の A0(ソケット位置)

テスター確認

  • ジャンパ線で Q3 の G を 3.3V に触れさせると、中間点 = VBATのちょうど半分(約3V)
  • ジャンパ線を離すと中間点はほぼ VBAT まで浮く(電流が流れていない証拠。故障ではない)

STEP 4XIAO を挿す

番号線の種類どこから → どこへ
㉕3.3VU1 の1番:OUT → XIAO の 3V3ピン(ソケット位置)
㉖GNDXIAO の GNDピン → GNDレール
  • 先にピンソケット(メス)だけを基板にはんだ付けし、配線が全部終わってから XIAO 本体を挿します
  • 挿す向きは「部品図鑑」の図のとおり(USBコネクタの位置で確認)
最重要: パソコンと USB でつなぐときは、必ず電池を抜くこと。電池と USB の電気がぶつかって XIAO が壊れることがあります。「電池を入れたまま USB を挿さない」と基板にマジックで書いておくくらいでちょうどいいです。

確認

  • 電池だけで XIAO の LED が点く(工場出荷ファームで確認可)

STEP 5TFmini Plus をつなぐ

番号線の種類どこから → どこへ
㉗5V5Vライン → TFmini の赤線
㉘GNDTFmini の黒線 → GNDレール
㉙UARTXIAO の D6(TX) → R7(1kΩ)→ TFmini の白線(RX)
㉚UARTTFmini の緑線(TX) → XIAO の D7(RX)

確認(テスト用ファームウェアを書き込んで)

  • 測定コマンドで TFmini が起動し、距離の数字が返ってくる
  • スリープ中は 5Vライン = 0V
  • 電流計(µAレンジ)を電池と直列に入れて、スリープ電流 90µA以下(目標 約50µA)

5こわさないための約束ごと

  • 電池を入れたまま USB をつながない(STEP 4 参照)
  • 向きのある部品は4つ: D1(帯の向き)・C4(長い足が+)・トランジスタ3個(1-2-3の並び)・レギュレータ2個(F33/F50の読み分け)。はんだ付け前に部品図鑑と照合
  • はんだ付けは「背の低い部品から」: 抵抗 → ダイオード → コンデンサ(小) → トランジスタ/レギュレータ → ソケット → 電解コンデンサ
  • トランジスタ・XIAO は静電気に弱いので、作業前に金属(水道の蛇口など)に触れて体の静電気を逃がす
  • 各ステップのテスター確認を飛ばさない——あとから原因を探すほうが何倍も大変
  • 屋外に持ち出す前に、部屋で数日間動かしっぱなしにして記録とスリープ電流を確認する
