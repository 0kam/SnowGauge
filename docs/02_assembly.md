## A. ブレッドボード版

### A-1. 何のために作るか

- PCB が届くまでの間に、ファームウェアの開発と動作確認をするための試作です。
- 回路は **PCB v1.2 と同一トポロジ**（電池電圧の分圧はスイッチ後のレール VBAT_SW に接続、Q3・R6・D3 は無し）。ここで動いたファームウェアは、そのまま PCB でも動きます。
- 学生の組み立て会では、はんだ付け前に回路を理解する練習台にもなります。

### A-2. 配線図（生成物）

**https://0kam.github.io/SnowGauge/breadboard_guide.html**

- 830 穴ブレッドボード 1 枚とジャンパワイヤで組めます。全体図 + STEP ごとの拡大図、各部品の両端の穴名（例 `c10`）、チェックリストが載っています。
- この HTML は `docs/gen_breadboard.py` が生成します。**手で編集しないでください**（直すときはスクリプトの `PARTS` を直して再生成）。
- XIAO は **USB コネクタを左**に向けて挿します。このとき
  上の列（e20〜e26）= `5V, GND, 3V3, D10, D9, D8, D7`、
  下の列（f20〜f26）= `D0/A0, D1, D2, D3, D4, D5, D6` です。逆向きに挿すと壊れるので、挿す前に指差し確認。

### A-3. ベンチでの約束（必読）

電源は「XIAO の USB」と「電池／安定化電源」の 2 系統があります。ジャンパ **⑩**（橙、`a10 → a22`、U1 の 3.3 V 出力 → XIAO の 3V3 ピン）が両者をつなぐ線です。

| したいこと | USB | 電池／安定化電源 | ジャンパ ⑩ |
|---|---|---|---|
| ファームウェアの書き込み・シェル操作 | 挿す | 外す（または ⑩ を抜いて併用） | **抜く** |
| USB でシェルを見ながらセンサ側を電池で動かす | 挿す | 入れる | **抜く**（XIAO は USB 給電、センサレールと分圧は電池給電。GND は共通のまま） |
| スリープ電流の測定・実運用の模擬 | **外す** | 入れる | 挿す |

- **⑩ を挿したまま USB と電池（安定化電源）を同時につないではいけません**（3V3 ピンへの外部給電と USB 給電がぶつかります）。
- 安定化電源で電池を代用するときは **6.0 V、電流制限 1 A 以上**（TFmini の起動時ピークは 500 mA）。
- 電源系のジャンパは短く太いものを使う（TFmini の突入電流でブレッドボードの接触抵抗が効く）。
- スリープ電流の最終評価は PCB で行います（ブレッドボードは接触・リークで数 µA 上振れします）。

### A-4. STEP 1〜5 の確認（要約）

各 STEP を組み終えたら、**テスターで下の値を確認してから次へ**。詳しい穴名は配線図のチェックリストを参照。

| STEP | 組むもの | 確認すること（テスターの黒棒は青レール = GND） |
|---|---|---|
| 1 | 電源部（D1、U1、C1/C2/C6） | 赤レール = 電池電圧 −0.2〜0.4 V。`c10`（U1 の OUT）= **3.25〜3.35 V** |
| 2 | XIAO と 3.3 V / GND のジャンパ | XIAO の 3V3 ピン（22 列）− GND ピン（21 列）= **3.3 V**（LED は点きません） |
| 3 | スイッチ（Q2・Q1）と 5 V 系（U2、C3/C4/C5） | 何もしないとき `e42`（5 V ノード）= **0 V**。ジャンパで `a28`（Q2 の G）を 3.3 V（`c10`）に触れさせると `e42` = **4.9〜5.1 V**、離すと 0 V。触れている間 `a32`（Q1 の G）≈ 0 V、`a33`（VBAT_SW）= 電池電圧 |
| 4 | 電池電圧の分圧（R1/R2 → A0） | `a28` を 3.3 V に触れさせている間 `a36`（分圧の中点）= **電池電圧のほぼ半分**。離すと **0 V** |
| 5 | TFmini（R7、4 本の線） | テスト FW で `rail on` → `tfmini raw 500` で距離フレームが届く。`rail off` → `e42` = 0 V。電池と直列の µA 電流計でスリープ **90 µA 以下** |

STEP 5 の TFmini の線: 赤 = +5 V（`e42`）、黒 = GND、緑 = TX → XIAO D7、白 = RX ← R7 ← XIAO D6。
実測（2026-09-03）: スリープ約 17〜18 µA、BLE アドバタイズ込みで約 26 µA（[measurements/2026-09-03_breadboard_current.md](measurements/2026-09-03_breadboard_current.md)）。

## B. PCB v1.2

### B-1. 基板の注文（JLCPCB、日本まで約 1 週間）

1. https://jlcpcb.com → 「Add gerber file」→ [pcb/SnowGauge_v1.2_gerbers.zip](../pcb/SnowGauge_v1.2_gerbers.zip) をアップロード
2. 設定: 2 層、64 × 50 mm（自動認識）、枚数 5（または 10）、厚さ 1.6 mm、HASL、緑 — **すべて既定値のままで可**
3. 配送: **DHL または OCS Express**（3〜4 日で届く。エコノミー便は数週間かかる）

基板の概要: 64 × 50 mm、2 層、部品はすべてリード部品（スルーホール）。裏面は GND ベタ。四隅に M3 穴（中心間 57 × 43 mm）。電池端子 J1 は下辺、TFmini 端子 J2 は右辺に出ます。

### B-2. 部品配置と向き

基板のシルク（白い印刷）に記号が書いてあります。**向きのある部品**は特に注意。

| 記号 | 部品 | 向き・注意 |
|---|---|---|
| D1 | 1N5819 | 帯（カソード）をシルクの **「K」** 側に。帯側が VBAT（回路の内側）、反対側が電池 + |
| U1 | NJU7223F33（3.3 V、常時） | TO-220F。印字面から見て左から **VOUT – VIN – GND**。シルクの外形（平らな面／タブ側）に合わせる |
| U2 | NJU7223F50（TFmini 版）/ NJU7223F33（TSD20 版） | U1 と同じピン並び **VOUT – VIN – GND**。シルク「U2: F50=TFmini / F33=TSD20」。型番の印字で読み分ける |
| Q1 | 2SJ334（P-ch、TO-220） | 印字面から見て左から **G – D – S** |
| Q2 | 2SK4017（N-ch、TO-251、小さい方） | 印字面から見て左から **G – D – S** |
| R1, R2 | 1 MΩ | 向きなし。分圧（VBAT_SW → A0） |
| R3 | 10 kΩ | 向きなし。D10（SENSOR_EN）→ Q2 ゲート |
| R4, R5 | 100 kΩ | 向きなし。R4 = Q2 ゲートプルダウン、R5 = Q1 の G-S プルアップ |
| R7 | 1 kΩ | 向きなし。D6（TX）→ TFmini 白 |
| C1, C2, C3, C5 | 0.1 µF | 向きなし。U1・U2 の入出力のすぐそば |
| C6 | 10 µF（5 mm ピッチ） | 向きなし。3.3 V レール |
| C4 | OS-CON 470 µF / 16 V | **極性あり**。長い足 = **+** をシルクの「+」側（5 V レール）へ。反対側が GND |
| J1 | 端子台 2P（5.08 mm） | 線の差し込み口を**基板の外（下辺）**へ向ける。シルク「+」「−」 |
| J2 | 端子台 2P × 2（連結して 4 極） | 2 個をスライドして 1 つにしてから差す。差し込み口を**右辺の外**へ。上から **RED(+5V) / BLK(GND) / GRN(TX) / WHT(RX)**（シルク「RED,BLK」「GRN,WHT」） |
| J3 | ピンヘッダ 1×4 | シルク「SCL SDA GND 3V3」。予備 I2C。省略可 |
| A1 | XIAO 用ピンソケット 1×7 × 2 | ソケットを 2 列はんだ付けし、XIAO は **USB コネクタをシルク「USB」の側（基板の上辺、U1・D1 のある側。電池端子 J1 の反対側）** に向けて挿す。上辺側は USB-C ケーブルが届くよう空けてあります |
| H1〜H4 | M3 穴 | スペーサ／ネジ |

### B-3. はんだ付けの順番（背の低いもの → 高いもの）

1. 抵抗 R1, R2, R3, R4, R5, R7（足を曲げて挿し、裏ではんだ付け、余った足を切る）
2. ダイオード D1（帯の向きを確認してから）
3. セラミックコンデンサ C1, C2, C3, C5, C6
4. ピンヘッダ J3（使う場合）
5. XIAO 用ピンソケット A1 × 2（まっすぐ立つように、1 ピンだけ仮止めして角度を直してから残りをはんだ付け。**XIAO はまだ挿さない**）
6. Q2（TO-251）
7. U1、Q1、U2（TO-220 系）
8. C4（OS-CON、極性を再確認）
9. 端子台 J1、J2（差し込み口を基板の外側へ）

はんだ付け後、裏面をルーペで見て**隣のパッドとつながっていないか**、はんだの不足がないかを確認。

### B-4. 通電チェック（XIAO を挿す前に）

テスターの黒棒は GND（J1 の「−」、または J3 の GND ピン）に当てます。電池ボックス（L91 ×4）または安定化電源 6.0 V を J1 につなぎます（赤 → +、黒 → −）。

| # | 測るところ | 期待値 | 意味 |
|---|---|---|---|
| 1 | D1 の「K」側（U1 の VIN 側） | 電池電圧 −0.2〜0.4 V | 逆接保護ダイオードを通った VBAT |
| 2 | U1 の VOUT（= XIAO ソケットの 3V3 位置、J3 の 3V3 ピン） | **3.25〜3.35 V** | 3.3 V 常時レール |
| 3 | J2 の RED（5 V レール） | **0 V** | センサレールは平常時 OFF |
| 4 | ジャンパ線で **XIAO ソケットの D10 位置**（= R3 の XIAO 側）を 3.3 V（J3 の 3V3 ピン）に触れさせながら J2 の RED | **4.9〜5.1 V**（TSD20 版: 3.25〜3.35 V）。離すと 0 V | SENSOR_EN = High で Q2 → Q1 → U2 が ON |
| 5 | 同じく D10 を 3.3 V に触れさせながら Q1 の D（U2 の VIN）= VBAT_SW | 電池電圧（離すと 0 V） | 高側スイッチが ON |
| 6 | 同じく D10 を 3.3 V に触れさせながら **XIAO ソケットの A0 位置**（R1/R2 の中点） | **電池電圧のほぼ半分**。離すと **0 V** | 分圧は VBAT_SW から給電（スリープ中は 0 V） |

全部合格したら電源を外し、XIAO を挿します（向きは B-2 の A1 を参照）。

### B-5. XIAO を挿してから

- **基板のシルク「NO USB WHILE BATTERY CONNECTED!」の通り、電池をつないだまま USB を挿さない。** 書き込みは電池を外して USB だけで行う（手順は [03_firmware.md](03_firmware.md)）。
- 書き込み後、USB を外し、電池をつなぐ。ファームウェアの `rail on` / `tfmini raw 500` 相当の確認と、電池と直列の µA 電流計でのスリープ電流測定（目標 ≤ 90 µA、ブレッドボード実測 ≈ 26 µA）を行う。
- TFmini の 4 本線は J2 に **RED / BLK / GRN / WHT** の順（上から）で締める。締めたあと軽く引いて抜けないことを確認。

## C. 筐体・設置（検討中）

### C-1. 筐体（プレースホルダ）

筐体は**検討中**です。前のプロトタイプではタカチ **BCAP091208G**（内寸 66 × 96 mm）を使い、PCB v1.2 はその 50 mm 辺を幅方向にして収まる寸法にしてあります。防水・光学窓（TFmini のレンズ前）・電池ボックスの固定方法が決まり次第、ここに追記します。

### C-2. 照準のルール（設計仕様書 §5・§4.5 より）

1. 幹に取り付けて**鉛直下向きに測らない**。幹の直下は樹冠と幹からの放射で雪が少なく（tree well）、過小評価になる。
2. **θ = 20〜30° の斜め照準**で、幹から 2〜5 m 離れた開けた雪面を狙う（取付高 4 m・θ 25° なら幹から約 1.9 m 先、斜距離約 4.4 m）。
3. 照準先に下草・倒木・吹き溜まりがないことをチェックリストで確認し、設置時に照準先の写真を残す。
4. 傾き θ は毎回 IMU が測るので、取付角は厳密でなくてよい（取付後のずれの検出にも使う）。
5. 積雪深 = (無雪時の基準斜距離 d0 − 現在の斜距離 d) × cos θ。**設置時に必ず ZERO（無雪面なら基準距離取得）または「積雪深の実測値からの基準設定」をアプリで行う。**

アプリでの ZERO・時刻合わせ・データ回収の手順は [04_app.md](04_app.md) を参照。

## 通電チェックで値が合わないとき

| 症状 | 疑う場所 |
|---|---|
| 赤レールに電池電圧が出ない | J1 の極性、D1 の向き（帯 = カソードが基板側 = VBAT） |
| 3.3 V が出ない／低い | U1 の向き（VOUT-VIN-GND）、C1/C2 のはんだ、U1 の VIN に電圧が来ているか |
| SENSOR_EN を High にしても 5 V が出ない | Q2 の向き（G-D-S）、R3/R4 の値（R3 = R4 = 10 kΩ は NG）、Q1 の向きと R5 |
| 5 V が常に出ている（切れない） | Q1 の G-S 間が短絡していないか、R5 の有無、Q2 の D-S 短絡 |
| A0 が Vbat/2 にならない | R1/R2 の値が同じか、分圧の上端が VBAT_SW（Q1 のドレイン側）に付いているか |
| TFmini から応答がない | J2 の配線色（赤 5V・黒 GND・緑 TX→D7・白 RX←D6）、R7 の有無、レールが 5 V か |
