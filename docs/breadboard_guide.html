SnowGauge ブレッドボード配線図

PCB が届くまでの開発・ファームウェア検証用に、はんだ付けなしで SnowGauge を組む配線図です。830 穴ブレッドボード 1 枚とジャンパワイヤで組めます。回路は PCB v1.2 と同一トポロジ（電池監視の分圧をスイッチ済みレールに接続。Q3・R6 は廃止）なので、ここで書いたファームウェアはそのまま PCB で動きます。

1座標の読み方

列番号（1〜63）×行（a〜e / f〜j）で穴を指定します。同じ列の a〜e、f〜j はそれぞれ内部でつながっています（中央の溝をまたぐと別グループ）。上下の赤・青の長いレールは横一列すべてつながっています。

  • 上の赤レール = VBAT（ダイオード通過後の電池+）／ 上の青レール = GND
  • 下の赤・青レールは使いません（すべて上のレールに戻します）
  • 例: c10 = 10 列目の c 行。部品の両端は図中の●の脇に穴名を書いてあります。レールへ行く線は同じ列のレール穴に挿してあれば十分です（レール上の位置は自由）

丸数字は下のチェックリストの番号。各部品・線の両端に穴名を表示しています（ステップごとの拡大図は §3）。

  • テスト FW で: rail on → tfmini raw 500 で距離フレーム受信、rail off → e42 = 0V
  • µA 電流計を電池と直列に: スリープ 90µA 以下（ブレッドボードは接触・リークで数 µA 上振れすることあり）

TFmini の線が細くて抜けやすい場合は、ピンヘッダ付きジャンパをかませるか、線先にピンを圧着してください。安定化電源で代用する場合は電流制限を 1A 以上 に（TFmini 起動時ピーク 500mA）。

4注意メモ

  • 電池を入れたまま USB をつながない（STEP 2 参照。例外は⑩を抜いた時のみ）
  • 向きがある部品: D1（帯）、C4（長い足が+）、U1/U2/Q1/Q2（1-2-3 の並び、印字面を手前に）。F33 と F50 は印字で読み分け
  • TFmini のピーク電流(500mA)はブレッドボードの接触抵抗に厳しいので、電源系のジャンパは短く太いものを。測距が不安定なら C4 の追加や配線短縮を試す
  • スリープ電流の最終評価は PCB で行う（ブレッドボードはリークが乗るため参考値）
  • 抵抗の代替値（手持ちで組む場合）: R3 は 150Ω〜2.2kΩ（R4 との分圧で Q2 のゲート電圧が 2.7V 以上になること。R3=R4=10k は NG）、R4・R5 は 10kΩ 可、R1/R2 は 同じ値なら 5k〜1M のどれでも（FW は「読み値 ×2」）、R7 は 1k〜5k。分圧は VBAT_SW 側なのでスリープ電流には影響しない
