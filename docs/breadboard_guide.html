SnowGauge ブレッドボード配線図

PCBが届くまでの開発・ファームウェア検証用に、はんだ付けなしでSnowGaugeを組む配線図です。830穴ブレッドボード1枚とジャンパワイヤで組めます。回路はPCB v1.2と同一トポロジ（電池監視の分圧をスイッチ済みレールに接続する改良版。Q3・R6は廃止）なので、ここで書いたファームウェアはそのままPCBで動きます。

1座標の読み方

列番号（1〜63）×行（a〜e / f〜j）で穴を指定します。同じ列のa〜e、f〜jはそれぞれ内部でつながっています（中央の溝をまたぐと別グループ）。上下の赤・青の長いレールは横一列すべてつながっています。

  • 上の赤レール = VBAT（ダイオード通過後の電池+）／ 上の青レール = GND
  • 下の青レールもGND（⑯のブリッジ線で上とつなぐ）。下の赤レールは使いません
  • 例: c10 = 10列目のc行

2配線図

VBAT GND 3.3V VBAT_SW(スイッチ後) 5V(測定時のみ) Q1ゲート 電圧測定 UART TX→白 UART 緑→RX

※ 図の曲線は「どの穴からどの穴へ」の対応を示すもので、実際のジャンパの這わせ方は自由です。丸数字は下のチェックリストと対応。

3組立チェックリスト

上から順に。各ステップ末尾のテスター確認に合格してから次へ。XIAOとTFminiを挿すのは電源確認のあとです。

番号部品/線挿す場所

④U1 NJU7223F33c10, c11, c12（印字面を手前: 10=OUT, 11=IN, 12=GND）
⑤ジャンパ 赤a11 → 赤レール
⑥電池ボックス 黒線上の青レール(GND)
⑦ジャンパ 黒a12 → 青レール
⑧C1 / C2 / C6C1: e11↔e12ㅤC2: d10↔d12ㅤC6(10µF): c10↔c12（向きなし）
  • 赤レール−青レール間: 電池電圧 −0.2〜0.35V
  • c10（U1のOUT）−青レール間: 3.25〜3.35V

STEP 2XIAO

番号部品/線挿す場所
⑨XIAO nRF52840 Sense列20〜26に溝をまたいで。USBコネクタが左（列20側）。上列(e)=D0〜D6 / 下列(f)=5V,GND,3V3,D10,D9,D8,D7
⑩ジャンパ 橙a10（U1のOUT列） → g22（3V3ピンの列）
⑪ジャンパ 黒g21 → 下の青レール
⑫ジャンパ 黒上の青レール ↔ 下の青レール（右端あたりでブリッジ）
  • 電池だけでXIAOのLEDが点灯する
最重要: パソコンとUSBでつなぐ時は必ず電池を抜く。向きを間違えて挿すと壊れるので、⑨は挿す前に指差し確認。

STEP 3スイッチと5V系

番号部品/線挿す場所
⑬Q2 2SK4017h28, h29, h30（印字面を手前: 28=G, 29=D, 30=S）
⑭R3 10kΩj23 ↔ j28（D10列 → Q2のG列）
⑮R4 100kΩi28 → 下の青レール
⑯ジャンパ 黒g30 → 下の青レール
⑰Q1 2SJ334c32, c33, c34（印字面を手前: 32=G, 33=D, 34=S）
⑱R5 100kΩb32 ↔ b34（GとSの間）
⑲ジャンパg29（Q2のD） → a32（Q1のG）
⑳ジャンパ 赤a34（Q1のS） → 赤レール
㉑U2 NJU7223F50c38, c39, c40（38=OUT, 39=IN, 40=GND）。TSD20版はここをF33に
㉒ジャンパa33（Q1のD） → a39（U2のIN）
㉓ジャンパ 黒a40 → 青レール
㉔C3 0.1µFe39 ↔ e40
㉕C4 OS-CON / C5 0.1µFC4: b42(+)↔b44(−) 極性注意・長い足が+ㅤC5: c42↔c44
㉖ジャンパa38（U2のOUT） → a42（5Vノード）
㉗ジャンパ 黒a44（C4の−） → 青レール
  • なにもしない時: e42−GND間 = 0V
  • ジャンパ線で j28（Q2のG）を 3.3V（c10）に触れさせる: e42 = 4.9〜5.1V、離すと0Vに戻る

STEP 4電池電圧の見張り（改良版: スイッチ済みレールから分圧）

番号部品/線挿す場所
㉘R1 1MΩc33（Q1のD=VBAT_SW） ↔ c36
㉙R2 1MΩb36 ↔ b41
㉚ジャンパ 黒a41 → 青レール
㉛ジャンパ 紫a36（分圧の中点） → a20（XIAOのA0列）
  • スイッチON中（上の確認と同時に）: a36−GND間 = 電池電圧のほぼ半分、OFF中は 0V

FWメモ: 電池電圧はセンサレールON中にA0を読む（読み値×2）。旧設計のD3・Q3・R6は廃止。

STEP 5TFmini Plus

番号部品/線挿す場所
㉜R7 1kΩa26（D6=TXの列） ↔ a31
㉝TFmini 白(RX)c31（R7の先）
㉞TFmini 緑(TX)h26（D7=RXの列）
㉟TFmini 赤(+5V)e42（5Vノード）
㊱TFmini 黒(GND)上の青レール
  • テストFWで: センサレールON → 距離データ受信、OFF → 5Vノード0V
  • µA電流計を電池と直列に: スリープ 90µA以下（ブレッドボードは接触・リークで数µA上振れすることあり）

TFminiの線が細くて抜けやすい場合は、ピンヘッダ付きジャンパをかませるか、線先にピンを圧着してください。

4注意メモ

  • 電池を入れたままUSBをつながない（STEP 2参照）
  • 向きがある部品: D1（帯）、C4（長い足が+）、U1/U2/Q1/Q2（1-2-3の並び、印字面を手前に）。F33とF50は印字で読み分け
  • TFminiのピーク電流(500mA)はブレッドボードの接触抵抗に厳しいので、電源系のジャンパは短く太いものを。測距が不安定ならC4の追加や配線短縮を試す
  • スリープ電流の最終評価はPCBで行う（ブレッドボードはリークが乗るため参考値）
